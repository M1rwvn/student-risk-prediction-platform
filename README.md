# Student Risk Prediction Platform

## Project Overview

An end-to-end machine learning project that builds a complete pipeline for predicting student risk levels using data preprocessing, feature engineering, machine learning models, and explainable AI techniques.

The project focuses on transforming raw data into meaningful insights through automated workflows, model evaluation, and interpretation of prediction results.

---

## Objectives

- Build a complete data processing and machine learning pipeline.
- Perform exploratory data analysis to understand patterns in the dataset.
- Develop and compare multiple machine learning models.
- Evaluate model performance using appropriate metrics.
- Apply explainable AI techniques to understand model decisions.

---

## Features

- Data preprocessing and cleaning pipeline.
- Feature engineering workflow.
- Exploratory Data Analysis (EDA).
- Machine learning model training.
- Model performance evaluation.
- Explainable AI analysis using SHAP.
- Interactive dashboard for prediction visualization.
